## ADDED Requirements

### Requirement: 有原句依据的可视化

提示词库 SHALL 调用有效模型生成含逐字引用的结构，经本地检查后以流程图、3D 分组或短文呈现。

#### Scenario: 从独立或停靠入口使用

- **WHEN** 用户在提示词库导入或选择条目并调用本功能
- **THEN** 可缩放并定位原句，生成结果跨重启离线复用，原文变更后提示更新，允许导出独立 HTML。

#### Scenario: 长流程和失败恢复

- **WHEN** 经逐字校验的结构包含 6、7 或 24 个节点、分支、跨行长边或回路
- **THEN** 内嵌及导出使用同一可缩放布局，保留完整标签和边。自动改用可用的本地布局不重复请求模型。
- **WHEN** 更新遇到连接、引用或布局错误，或等待期间切换条目
- **THEN** 保留原文和上次可用图，明确错误来源，其他条目的图和状态保持正确。

#### Scenario: 重复原句

- **WHEN** 节点或连线的逐字引用在原文出现多次
- **THEN** 内嵌阅读与独立 HTML 仅使用可核对的 UTF-16 偏移或能唯一定位的上下文。证据不足时提示多处匹配，用户可逐处查看。

#### Scenario: 详情打开 Archify 阅读页

- **WHEN** 用户首次点击可视化
- **THEN** 专用连接优先，继承模式使用全局连接，包括已授权的订阅。流程节点显示短动作和判断，完整依据在图下。生成的独立 HTML 在原文旁，由系统默认浏览器打开；只读 Skill 使用组件私有目录。
- **WHEN** 再次打开、移动或修改原文
- **THEN** 直接打开已有结果，原文变更显示「原文已更新」，由用户主动重新生成。失败保留旧文件，同名非关联 HTML 保留。
