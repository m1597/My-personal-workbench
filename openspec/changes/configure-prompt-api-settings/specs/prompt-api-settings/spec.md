## ADDED Requirements

### Requirement: 提示词仓库共享连接设置

仓库 MUST 提供独立可用的设置入口，通过共享存储编辑本组件的连接，并接受全局设置的变更。

#### Scenario: 双向更新

- **WHEN** 用户在仓库设置中保存单独连接或选择已有连接
- **THEN** 工作台对应组件立即显示新状态；全局修改后仓库中也显示最新设置，已有密钥只显示是否设置。

#### Scenario: 本地使用与异常恢复

- **WHEN** 用户尚未配置 API 或配置服务暂不可用
- **THEN** 用户仍可浏览、编辑、搜索与插入提示词，打开组件不会弹出凭据表单。

### Requirement: 固定动作执行连接

仓库 MUST 根据输入类型展示工具集实际执行用途、连接状态及所用模型。

#### Scenario: 工具集更新

- **WHEN** 用户选择图片动作，或工具集修改相应用途的绑定
- **THEN** 固定动作区域显示最新的工具集执行连接，不向模板文件和动作索引写入凭据。
