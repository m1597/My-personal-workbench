# Design

## Context

本机已安装 OpenSpec 1.17.0，仓库此前仅有历史 R02 Markdown 和 ADR。

## Goals / Non-Goals

**Goals:** 采用本机内置 spec-driven 模板、中文正文及严格校验。

**Non-Goals:** 业务开发、全局配置变更、重装 CLI 或技能。

## Decisions

项目内保存变更与现行能力规范。ADR 只记长期选择及理由。保留 R02 原址，避免改写已完成任务的审计记录。此次采用标准格式的决定由 ADR-003 追踪。

## Risks / Trade-offs

目录归档后路径会变化，完成时更新任务索引。小修沿用任务记录，避免重复撰写。后续改变流程通过新的变更和 ADR 追踪。
