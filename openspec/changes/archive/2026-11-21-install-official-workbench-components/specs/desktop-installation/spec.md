## ADDED Requirements

### Requirement: 在工作台设置安装正式组件

安装版工作台 SHALL 在全局设置「组件管理」列出 Music、文件库和工具集，并仅对缺失或安装失败的组件提供安装操作。

#### Scenario: 从只安装工作台开始

- **WHEN** 用户在设置中选择缺失的组件
- **THEN** 工作台从官方仓库的最新正式发行中选择该产品的 Windows x64 安装器，显示下载进度，核对资产地址、字节数及 SHA-256 后运行，并在发现可用的目标版本后显示已安装

#### Scenario: 下载校验或安装后检测失败

- **WHEN** 正式资产缺失、传输或摘要校验失败、安装器失败或安装后未发现目标版本
- **THEN** 该行显示失败阶段和单项重试，校验失败的文件不执行，重新点击后再次检查正式发行

#### Scenario: 用户已有组件或切换页面

- **WHEN** 用户打开或重新进入组件管理
- **THEN** 页面识别宿主目录内或已登记的完整组件，并显示版本，进行中的安装仍显示进度，避免重复安装
