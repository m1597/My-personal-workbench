# Spec Delta

## Purpose

让用户决定四个内置模块分别显示在哪个系统窗口，能把其中一个或全部拖出工作台，在需要时按实际落点接回，并继续此前的导航、查看和布局操作。

## ADDED Requirements

### Requirement: 任一模块可独立使用

公共宿主 MUST 支持四个内置模块单独启动和同时分离，每个模块最多有一个活动实例。

#### Scenario: 四个窗口共存

- **WHEN** 用户将四个模块逐个从标签栏拖出整个工作台并在窗口外松手
- **THEN** 每个模块在落点附近出现独立窗口，原标签移除，空工作台仍可用。移动、缩放或关闭其中一个独立窗口只影响该模块。

#### Scenario: 单独启动及重复打开

- **WHEN** 工作台未打开，用户从桌面入口选择某个模块，随后再次打开该模块
- **THEN** 首次只显示该模块的独立窗口，重复打开聚焦已有窗口。关闭工作台后已分离窗口仍可用。

### Requirement: 按落点接回并保留状态

宿主 MUST 支持从独立窗口标题栏拖回可见面板中央或四边，并保持其他模块的位置和已有状态。

#### Scenario: 混合停靠

- **WHEN** 用户保留若干独立窗口，将另一个模块拖向工作台面板中央或左、右、上、下边缘松手
- **THEN** 中央成为同组标签，边缘形成对应侧的相邻分屏；其他独立窗口仍可使用，导航搜索文字在同次运行的往返中保留。

#### Scenario: 取消和失败

- **WHEN** 用户按 Esc 取消、在遮挡窗口上释放或接入超时
- **THEN** 模块继续在原位置可用，布局和其他模块的选择保持有效，重试不会留下重复标签。

#### Scenario: 旧布局与空布局

- **WHEN** 用户通过原桌面入口恢复已有四模块布局或合法空布局
- **THEN** 工作台继续使用原 profile 和布局键，恢复原有分组、尺寸及活动标签，已关闭模块可从窗口菜单重开。
