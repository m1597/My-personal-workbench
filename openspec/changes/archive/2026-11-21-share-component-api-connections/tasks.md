## 桌面验收

- 从桌面 FitBay.cmd 在隔离资料目录打开全局设置。总览列出 Music、提示词仓库、工具集翻译与视觉用途，选择用途后在同一页编辑。见[桌面入口记录](../../../../tmp/desktop-check-22550-17040/desktop-verified.json)和[总览截图](../../../../tmp/api-settings-0Ee8UT/overview.png)。
- Music 的全局保存、独立窗口回读、组件修改、全局回读通过。打开未配置的独立 Music 后可进入找歌，点击生成推荐才进入配置。另用独立打包的 FitBay Music.exe 验证无配置打开、主动生成推荐直达配置、保存随机凭据并回读。用隔离测试资料验证升级后首次打开全局页可见旧模型，旧表单只改模型仍保留自定义地址及凭据。四种协议以本地服务逐一断言实际路径、鉴权及 401 错误脱敏。复验脚本为 scripts/check-shared-api-page.mjs 与 scripts/check-music-connection-upgrade.mjs。
- 工具集独立进程与工作台同时编辑、显式复用和分离、旧密钥迁移、无配置先截图再直达配置通过。用本地服务分别断言翻译和视觉请求的地址、模型及输入内容。[工具集实测](../../../../docs/changes/2026-11-20-desktop-toolkit.md)。
- 提示词仓库在独立与停靠入口编辑共享连接，固定动作显示实际执行连接。见[组件验收记录](../../configure-prompt-api-settings/tasks.md)。系统凭据保护使用 Windows 当前用户 DPAPI，测试用随机密钥，只记录匹配结果。
- 本轮模型请求使用本机测试服务，未验证商业模型账户的连通性或计费。未执行覆盖安装或发布版本。
