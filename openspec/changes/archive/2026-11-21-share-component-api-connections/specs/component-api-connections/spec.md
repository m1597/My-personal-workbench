## ADDED Requirements

### Requirement: 总览与本地入口

工作台 SHALL 在齿轮设置的「API 与模型」中按已安装组件列出组件、用途、连接与状态。用户选中一行后可在页内编辑地址、密钥、协议及模型。保存后，组件设置与全局设置中打开的同一用途 SHALL 自动更新。

#### Scenario: 总览与本地入口

- **WHEN** 从全局或独立组件设置更换配置
- **THEN** 另一入口立即显示相同地址、模型和密钥配置状态。

### Requirement: 连接复用

系统 SHALL 使用选中连接，单独配置时其他用途不受影响。

#### Scenario: 连接复用

- **WHEN** 显式复用已有连接或切换为单独配置
- **THEN** 使用选中连接，单独配置时其他用途不受影响。

### Requirement: 独立模型

系统 SHALL 分别调用对应模型，独立安装仍可配置。

#### Scenario: 独立模型

- **WHEN** 为工具翻译与视觉选择不同服务
- **THEN** 分别调用对应模型，独立安装仍可配置。

### Requirement: 兼容与保护

系统 SHALL 沿用原设置，凭据由系统保护，界面默认遮盖，错误、日志及证据不含明文。

#### Scenario: 兼容与保护

- **WHEN** 升级现有 Music 或工具集配置
- **THEN** 沿用原设置，凭据由系统保护，界面默认遮盖，错误、日志及证据不含明文。

### Requirement: 按需配置

系统 SHALL 本地功能可用，调用需要 API 的功能时可直接进入对应设置。

#### Scenario: 按需配置

- **WHEN** 在尚未配置时打开组件并使用本地功能
- **THEN** 本地功能可用，调用需要 API 的功能时可直接进入对应设置。
