# Proposal

## Why

桌面启动器的两个入口分别启动日常工作台和隔离示例宿主。示例宿主只识别自己的窗口，用户拖到已经打开的日常工作台时没有接收方。原型即使命中，也固定加入模块 2。

## What Changes

让两个入口连接同一受限宿主。拖动独立组件的系统标题栏，工作台按指针位置显示吸附预览。松手后组件进入对应标签组或分屏，支持缩放；从面板标签拖出工作台后成为独立系统窗口，两种操作均无需点击按钮。

## Capabilities

### New Capabilities

- `component-docking` 管理组件窗口与工作台面板之间的位置选择和视图交接。

### Modified Capabilities

无。

## Impact

涉及桌面启动器、Electron 宿主、Dockview 装配和布局保存。保留当前日常 profile、已确认的深色玻璃和独立启动方式。范围限于现有示例。
