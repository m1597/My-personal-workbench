# Spec Delta

## Purpose

让同一个已部署组件可以在独立系统窗口和日常工作台面板之间通过自然拖放来回切换。用户可以用落点选择标签分组或分屏位置，切换前后的输入、选择和正在进行的操作保持连续。

## ADDED Requirements

### Requirement: 原生窗口拖入日常工作台

宿主 MUST 支持先启动任一入口，随后把独立示例窗口拖入已经打开的日常工作台。

#### Scenario: 拖入分组或分屏

- **WHEN** 用户拖动系统标题栏经过可见面板的中央或上、下、左、右边缘
- **THEN** 目标区域显示与落点对应的预览，松手后中央合并标签，边缘创建相应方向的分屏，可按普通面板调整尺寸，原独立窗口收起。

#### Scenario: 取消或未命中

- **WHEN** 用户按 Escape、在非目标窗口上松手或只调整窗口大小
- **THEN** 原窗口继续独立显示，工作台不新增模块，预览清除。

### Requirement: 从组件标签拖出成为独立系统窗口

宿主 MUST 允许用户直接拖动组件自己的 Dockview 标签完成分离，整个往返不需要点击分离或合并按钮。

#### Scenario: 拖出再吸附

- **WHEN** 用户把组件标签拖过工作台外边界并松手
- **THEN** 组件在松手处附近显示为可独立移动、缩放的系统窗口，原标签移除；再次拖入可以继续使用原会话、输入、计数与队列选择。

#### Scenario: 工作台内重排

- **WHEN** 用户只在工作台内拖动标签或取消拖动
- **THEN** 工作台内继续由 Dockview 完成重排或取消，不弹出独立窗口。

### Requirement: 组件外观与普通面板统一

组件 MUST 与普通面板共用主题、单层面板材质、控件和浮层配色。

#### Scenario: 切换组件承载方式

- **WHEN** 示例从独立窗口进入工作台再分离
- **THEN** 有效面板底色与普通面板一致，输入、菜单选中态与会话保持，减少透明和高对比度下使用共同回退。

#### Scenario: 宿主管理的工具窗口

- **WHEN** 从工作台打开组件及其辅助工具窗口
- **THEN** 托盘和任务栏由工作台提供唯一入口。独立启动的工具集保留自己的入口。
