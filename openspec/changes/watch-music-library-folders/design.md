# 设计

选择器返回目录后，Music 提供默认未勾选的原生复选框。只有完成导入的批次会新增持续收录目录；取消选择或取消导入不新增授权。旧 profile 的已导入目录默认保持一次性导入。

每个订阅目录树的首次启动检查和重连检查会枚举目录。运行时通过文件系统通知标记变动目录，短时间内合并同目录事件，复核目录身份及更新时间以检测断开、变更和恢复；只在变化目录比较文件签名并解析新歌或修改后的文件。SQLite 保存成功处理的文件签名，未变文件保持同一曲目 ID。遇到盘符离线仅修改可用状态，保留歌单、收藏。歌词沿用同名 LRC 解析及播放器刷新事件。

Node 官方说明 Windows 监视句柄与被监视目录绑定，删除或移动时可能失效，因此需要重建监听并补查。使用现有 Node 和 SQLite，无新增运行依赖。[Node fs.watch caveats](https://nodejs.org/api/fs.html#caveats)
