# Design

## Context

现有桌面入口从同一 profile 的公共宿主启动，示例已有 WebContentsView 双向移挂、布局事务和受限桥。正式安装包使用独立入口。

## Goals / Non-Goals

本期只部署第一方音乐组件。第三方市场、SDK、全局模型平台及正式安装升级另行规划。

## Decisions

- 给示例和音乐分配独立且固定的宿主身份及布局 ID，沿用现有布局键。一个音乐视图只创建一个音频元素。
- 使用受控主进程单写入 SQLite，保存推荐、候选选择、队列和恢复点；音频使用用户选定目录，路径只在主进程解析。详情见 ADR-006。
- 离线目录提供可验证的自有合成 WAV；真实目录与解析分别验收。真实模型与曲源材料缺失时禁用其入口。

## Risks / Trade-offs

原生拖放和听辨需 Windows 人工验收；后台用真实媒体时间和 WebContents 身份验证。写满用可重复故障注入覆盖，跨卷须记录卷与清理范围。
