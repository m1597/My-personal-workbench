## 磁盘核对与恢复

按 [Node.js 文件系统文档](https://github.com/nodejs/node/blob/main/doc/api/fs.md) 的 fs.watch 限制，监听只触发重新读取，启动与恢复焦点也从磁盘取快照。当前目录、常用目录和调用目录各自监听，失效位置只探测可读性，重新可读后重建监听。虚拟盘保留用户选用的盘符，文件访问逐项核对真实路径。

对已选文件记录设备号和文件号，结合最近的路径通知跟随普通改名或同卷移动。文件消失时，按原列表中的文件顺序选择下一项。跨卷移动由文件系统表现为复制和删除，按新路径重新发现。缩略图按可见区请求，替换同路径图片后重新解码。
