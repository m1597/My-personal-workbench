## 合并完成条件：八项功能与五标签导航

本清单同时覆盖前述八项和本节。两部分采用同一最终构建、独立 profile、后台静音真实界面核验，并核对桌面入口后统一交付。前述分项结果保留，导航影响的路径在下列用例重验。

- [x] 最终构建从工作台窗口菜单进入 Music，宽窄停靠均显示「曲库、歌单、在线找歌、AI 推荐、动态」；右侧下载任务、问号、收起、隐藏和更多中的音乐设置可用；迷你栏保持单行。
- [x] 核对曲库范围和歌单范围，旧歌单顺序、成员和管理操作；创建时选择本地歌曲。
- [x] 新歌单页真实混选本地和在线，记录请求与成功/失败，验证自动标记和离线回放。
- [x] 在线找歌跨平台保留词，按版本试听、下载及免下载入歌单。AI 推荐的「用当前歌曲」不触发模型或清批，手动生成才触发；使用五首快速听。
