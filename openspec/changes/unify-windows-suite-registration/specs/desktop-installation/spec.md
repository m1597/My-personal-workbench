## ADDED Requirements

### Requirement: 一套 FitBay 的 Windows 安装登记

安装器 SHALL 为当前用户提供一个可见 FitBay 安装项，保留组件独立安装、发现、升级和移除的能力。

#### Scenario: 单独覆盖工作台接管旧组件

- **WHEN** 新工作台覆盖旧工作台，旧登记组件实际位于子目录或其他盘的独立目录
- **THEN** 安装器核对每项产品身份、登记路径与真实文件后隐藏对应旧安装项，组件仍从其已登记目录打开并原地升级

#### Scenario: 只有独立组件

- **WHEN** 用户先安装独立组件，随后补装其他组件或工作台
- **THEN** 套件保有一个可见维护入口，并选择可用控制产品执行整套卸载

#### Scenario: 工作台替换与单项移除

- **WHEN** 工作台安装器使用更新参数替换旧工作台，或用户在工作台内移除一个组件
- **THEN** 其余组件、个人数据和对应可用入口保留，同根残留副本不会覆盖有效的外置组件登记

#### Scenario: 完整移除后重新安装

- **WHEN** 用户在 Windows 已安装应用中移除 FitBay，随后重新安装
- **THEN** 整套卸载先核对产品并保留非产品文件、用户配置及凭据，重新安装可识别原安装目录且拒绝覆盖碰撞文件

#### Scenario: 覆盖开始前原登记身份校验失败

- **WHEN** 旧产品登记、磁盘清单、版本、原路径或固定卸载器不匹配
- **THEN** 安装器在调用旧卸载器或写入产品载荷前退出，保留原有文件与登记

#### Scenario: 旧组件路径冲突或被接管后失效

- **WHEN** 已核实身份的两个产品目录重叠且不属于工作台与其约定组件子目录
- **THEN** 覆盖预验、登记及整套卸载均拒绝本次操作，防止隐藏冲突产品或移除其文件
- **WHEN** 单个旧组件的身份无法再核实，而其余产品可以正常维护
- **THEN** 套件恢复该组件曾由套件隐藏的条目，只维护仍能核实的产品，保留异常组件的路径、文件及卸载命令
