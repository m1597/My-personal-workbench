## Context

每个产品的 NSIS 安装器保有固定产品 ID、安装路径和固定文件清单。旧客户端也从这些产品键查找覆盖升级入口。

## Decisions

- 在当前用户的 64 位卸载注册表中增加 FitBay 入口。工作台优先承载整套卸载，仅装独立组件时由首个支持套件维护的组件承载。
- 仅在核对旧 GUID 目录、产品标识和版本、真实可执行文件、固定卸载器和原卸载命令后隐藏旧项。用 SystemComponent 保留原产品覆盖升级所需的登记。
- 通过独立的整套卸载参数区分 Windows 设置操作和工作台内单项移除。更新旧版时使用原 --updated 语义，避免组件随宿主覆盖而被连带移除。
- 已登记工作台使用验证后的组件登记。未登记的展开工作台优先发现其相邻组件，便于隔离验收。独立组件目录与宿主子目录都沿用历史位置。
- 整套卸载先预检所有相关目录、标记和卸载器，子产品成功退出并确认产品文件消失后才继续，最后移除控制产品。删除范围由各产品固定文件清单决定，用户数据和非产品文件保留。
