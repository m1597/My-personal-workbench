## ADDED Requirements

### Requirement: 用户订阅连接

工作台 SHALL 在 API 与模型提供官方浏览器同意、账号与套餐状态、模型选择、撤销及重新授权，凭据受系统保护。组件主进程按专用优先于默认的顺序选择连接。

#### Scenario: 授权账号存在但无可用视觉模型

- **WHEN** 用户将订阅连接设为默认，并从工具集调用图像功能
- **THEN** 仅当套餐模型具有图像输入能力时发送；否则提示所需能力，保留账号连接。

#### Scenario: 续期、额度或撤销

- **WHEN** 调用套餐且授权即将到期、已撤销或额度已用尽
- **THEN** 平台对即将到期的令牌续期；授权失效提示重新授权，额度用尽提示稍后再试，同次任务均不切换 API Key。
