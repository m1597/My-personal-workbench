## ADDED Requirements

### Requirement: 按用途继承默认连接

平台 SHALL 工作台 API 与模型提供默认连接、设为默认和恢复默认。组件使用同一存储，专用配置优先。

#### Scenario: 默认连接仅支持文本，Music 有专用连接

- **WHEN** 默认连接仅支持文本，Music 有专用连接
- **THEN** Music 使用专用配置，工具集翻译继承默认，视觉用途要求视觉能力。恢复默认后其他窗口立即读取继承值。

### Requirement: 保留旧连接与凭据配对

宿主 SHALL 从同一绑定或同一旧账号读取服务地址、协议、模型和凭据。只有缺省地址的旧版预设账号才使用供应商预设地址。

#### Scenario: 不同资料目录各有两个服务

- **WHEN** 用户恢复已配置的 Music 账号，或切换到仍有旧凭据的另一个账号
- **THEN** 模型请求到所选账号的原地址；其他服务的凭据不会随请求发送。两个地址字段冲突时，在解密或联网前拒绝直接调用，供用户重新配置。

### Requirement: Music 使用有效订阅推荐

Music SHALL 在推荐入口使用工作台解析出的订阅连接，复用歌曲和公开歌单的输入约束及结果校验；单独选择 API Key 时使用对应协议。

#### Scenario: 默认订阅与专用密钥

- **WHEN** 用户以继承的订阅推荐五首，再将 Music 切换为专用 API Key
- **THEN** 首次调用由平台订阅服务执行，切换后使用 Music 的密钥和模型。订阅额度不足时显示原错误，终止这次请求。
