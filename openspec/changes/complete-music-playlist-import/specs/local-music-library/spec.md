# Spec Delta

## ADDED Requirements

### Requirement: 导入旧歌单

Music SHALL 接受用户选择或拖入的 UTF-8 M3U/M3U8，并在建单前展示本地匹配结果。

#### Scenario: 相对路径、换盘和同名文件

- **WHEN** 旧歌单包含中文、相对路径、已移动的录音、重名或失效条目
- **THEN** 用户可确认准确匹配、选择候选、补选或跳过缺失项，最终歌单保留原顺序并去除重复项。

### Requirement: 从全部歌曲导入歌单

Music SHALL 在「曲库 → 全部歌曲」页头将「添加文件」「添加文件夹」「导入歌单」放在同一组，最后一个入口复用 Music 既有 M3U/M3U8 导入预览。

#### Scenario: 保留浏览现场

- **WHEN** 用户搜索并滚动曲库，从页头选择歌单，确认创建或取消
- **THEN** 返回原搜索和滚动位置；确认后新歌单可在歌单页访问。格式错误时原位提示，可重新选择。
