# 0.2.3 候选跨组件验收

上轮在 0.2.1 安装版复现四分屏色差，检查了 0.2.2 包内程序的同屏截图及控件颜色；Windows 安装任务实际验了升级、桌面快捷方式、四分屏材质参数、文件库分离和停靠。桌面快捷方式数量与运行中的任务栏按钮数量属于两项独立的验收。以往工具集专项替换过屏幕采集源及剪贴板写入，没有证明用户桌面的框选能复制出正确图像。[上轮报告](2026-11-21-installed-material-shortcuts.md) · [既有工具集专项](../../scripts/check-toolkit.mjs)

本轮候选为 Windows x64 0.2.3，提交 23877c8，Windows 构建 44918281041。已对下载的全部六项产物回算 SHA-256。完整离线包摘要为 51994d62fc5623c3c0980ed9e5e63e83a5fb8afaf5775bd27ec295f387aebab0。本机从该批安装器展开产品并运行真实 EXE，各专项使用新 profile。安装和升级由同批构建的干净 Windows 任务执行。

## 独立复验记录

- 按本轮截图顺序打开三组件并保留第四格快速开始，采集 Win32 整窗截图。调整三个材质参数后，三处根面板均透明且参数一致；文件库分离、再停靠通过。六个独立及停靠设置入口均可进入分类页面并返回。Music 保留检索词和设置分类，文件库保留多选和滚动量，工具集在两种窗口返回后仍有原文和新文本。[同屏原图](../images/integration/preview-023/four.png) · [设置截图](../../tmp/settings-shell-o4Z3cq/music-docked-settings.png)
- 三个菜单项的四列横坐标逐行相同。读取快速开始、菜单、标签伪元素的计算样式，三处使用相同的非空工具箱蒙版及当前文字颜色。[菜单原图](../images/integration/preview-023/menu.png)
- 通过 Explorer 任务列表读取实际应用标识。独立工具集有入口；从宿主打开设置、截图时，该工具集入口消失，候选仅有宿主按钮。日常安装的工作台同期另有自己的按钮。新装全选、0.2.1 升级到 0.2.3 均只留一个指向工作台的桌面入口，其他软件的同名目标保留，四个目录及标记保留。[任务栏记录](../../tmp/qa-next/taskbar-live.log) · [Windows 候选安装验收](https://github.com/m1597/My-personal-workbench/actions/runs/44918281041)
- 停靠、独立和系统快捷键三个入口各连续复制两次，用真实系统剪贴板粘贴到编辑区，六次整图 PNG 比对通过。框选显示红绿样张和复制、保存、贴图、标注操作。各入口 Esc 后遮罩关闭；另在正常显示模式从停靠入口实测，退出时 Win32 再次命中下层样张窗口。同一选区取色按取样点原始像素核对，测距按实际像素比例核对，系统 OCR 识别出 FITBAY 321。首轮量测对比点靠近文字边缘，修正为取同一物理像素后复验。全程未移动系统鼠标。[选区原图](../images/integration/preview-023/selection.png) · [三入口记录](../../tmp/qa-next/capture-ci.log) · [原生窗口命中](../../tmp/qa-next/native2.log)
- 文件库空格打开和关闭文本预览；多选两个测试 PNG，直接交给工具集生成两张 800 × 600 副本，再预览并执行重命名。文件库自动移除旧文件名，目录中仍有两个 PNG。[重命名后的文件库](../images/integration/preview-023/renamed.png) · [联动记录](../../tmp/qa-next/file-ci.log)

本轮截图为后台原生窗口采集，壁纸合成效果取决于实际桌面。真实粘贴改写了系统剪贴板；预验尝试恢复原内容时 Windows 返回 CloseClipboard 失败，未能确认恢复。最后一次验收写入的是测试选区。未在用户日常安装目录执行升级。
