# 工具集桌面交接

2026-11-22 核实桌面 `D:/Desktop/FitBay.cmd` 调用本仓库 `scripts/open-workbench.cmd --workbench`。本地构建 `npm run build:prototype` 和桌面入口 `--check` 通过。测试使用此构建的 Electron、dist/component-prototype/host、out/renderer/index.html 及 components/toolkit，以临时 profile 运行。

| 功能       | 入口、操作与实测结果                                                                                                                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 截图       | 工作台组件菜单打开工具集。框选红绿字样、用铅笔画线并复制到独立接收窗口，再从系统保存对话框保存。同尺寸 PNG 解码后整图逐像素一致。独立窗口和系统快捷键连续截图粘贴也通过，Esc 退出后可再次截图。另有一次前台采样受其他屏幕内容影响，比对失败；隔离复测再次通过三入口、标注和本地 OCR。 |
| 材质与返回 | 在实际工作台设置分别把透明度和亮度调到 0 和 100，已打开的独立窗口同步变化。停靠首页透明，设置使用相同的窗格背景。独立窗口宽 320 时填入长服务地址，横向溢出为零。切换 API 分类后，壳、内容区与布局容器均无焦点轮廓，返回保持首页可用。                                                 |
| 快捷键     | 两入口共用平台录制器。隔离测试保存单键 F8、取消录制、与现有动作冲突、停用取色、单项和全部恢复。两次重启保留绑定及启停状态。从停靠页录制组合键后用 Windows 实际按键触发取色，点击颜色后读回系统剪贴板。其他进程占用默认键时回报冲突；停用工具可恢复其默认绑定。                        |
| 通知区域   | 在宿主与工具集两个进程中读取存活的原生 Electron Tray，并调用 getBounds。冷启动停靠为 1+0，二次独立启动为 1+1，重新进入停靠首页为 1+0，再从独立入口启动为 1+1。宿主退出后，纯停靠进程退出，独立使用的窗口继续运行。平台组也用重新构建的宿主复验四次转换。                              |
| 任务栏     | 集成组用正常任务栏参数和屏幕外窗口，实际读取 Explorer。在开发用 Electron 分组中新增一个运行窗口，三个内嵌组件没有额外按钮。工具集组从停靠打开截图、贴图、返回后按 FitBay 字样查找任务栏按钮未命中，未将该次读数作为通过证据。前版已有贴图打开时的单按钮实读。                         |

## 复测

- `node scripts/check-toolkit-shell.mjs` 从实际渲染的工作台设置调整滑块，打开工具集设置、切换分类、返回，并检查托盘所有者与宿主退出。
- `node scripts/check-toolkit-runtime.mjs` 验证 F8、冲突、恢复和重启。
- `python scripts/toolkit-color-desktop.py` 验证 Windows 剪贴板、截图、保存与取色。单独检查取色可加 `--colors-only`。前台运行应提前提醒；脚本备存剪贴板，完成后尝试恢复原焦点。
- 真实外部模型按用户安排留待自行验证。本轮未制作或发布候选安装包，也未触发远程 CI。Explorer 通知区域含折叠项的全桌面图标总数未逐项人工清点。
