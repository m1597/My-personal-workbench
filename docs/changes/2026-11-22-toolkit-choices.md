# 工具集选择器和连接来源

开发工作树为 `D:/Desktop/Projects/FitBay-teams/toolkit`，分支为 `team/toolkit`。独立窗口、停靠窗格共用平台 ChoiceDropdown 和窗口当前材质。用途、连接、协议、截图标注形状以及图片配对均已接入。进入设置后立即点击 API 分类，异步加载完成仍停留在用户所选页。

| 隔离桌面入口   | 操作与可观察结果                                                                                                                                                                            |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 独立工具集     | 在 340 像素窗宽展开「连接」，看到继承、单独配置和可复用连接。文字用途读回默认模型；改为单独配置后只改变此用途。未标记图像的默认连接不能自动用于视觉，标记后已打开的设置页显示更新后的模型。 |
| 停靠工具集     | 在「组件 → 工具集 → 设置 → API 与模型」展开连接列表，将专用文字连接恢复为继承，两处均显示默认模型。共用库读回的来源由 dedicated 变为 default。                                              |
| 截图与文件配对 | 框选后在标注工具栏展开形状，选中矩形，取消标注和 Esc 后遮罩关闭。独立配对子页读取临时 PNG 和 TXT，选中提示词后生成可确认的改名预览。文件选择器应答使用测试文件，改名未执行。                |

[独立窄窗的展开状态](../images/toolkit-choices/standalone-open.png) · [停靠窗格的展开状态](../images/toolkit-choices/dock-open.png)
