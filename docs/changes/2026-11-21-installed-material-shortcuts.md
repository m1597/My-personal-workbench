# 安装版四分屏材质与桌面入口复验

## 0.2.1 已安装版本

从 Windows 安装登记找到 `D:\FitBay` 及其下的 Music、Toolkit、Prompts，四份已安装产品清单均为 0.2.1。用空白临时 profile 启动实际的 `FitBay.exe`，核对 Electron 的安装态、运行路径、profile 及窗口不可获焦。通过快速开始打开 Music 并进入「曲库」，再从「组件」依次打开工具集和文件库，形成与用户截图相同的四格。使用 Win32 PrintWindow 在后台一次捕获整个宿主窗口，包含两个原生子视图。离屏采集不复现用户壁纸的 Acrylic 合成。

**复现色差。** 左上 Music、右下快速开始可见中性灰底。右上工具集从偏蓝灰渐变过渡到深蓝灰，工具卡片和按钮也偏蓝。左下文件库从左上灰蓝过渡到右下深灰，按钮描边比 Music 更亮。[0.2.1 实机同屏原图](../images/integration/installed-0.2.1-four.png)

运行时样式与截图一致。工具集停靠面板渐变两端为 `rgba(48,57,71,.87)` 和 `rgba(32,38,50,.93)`；文件库主面板渐变终点为 `rgb(40,44,52)`。Music「添加文件」与文件库「打开文件夹」的底色均为半透明白色，但描边分别为 `rgba(255,255,255,.09)` 和 `rgb(104,116,134)`，圆角分别为 6 和 5 CSS px。[本机运行记录](../../tmp/qa-four-installed/run-9i8uqe/facts.json)

本机桌面清理后枚举快捷方式并解析目标，只发现「FitBay 工作台」指向 `D:\FitBay\FitBay.exe`。清理发生在本次核对前，安装及升级阶段的数量须在干净 Windows 环境复验。

## 平台组配色修复的本地预验

使用平台组从 0.2.1 安装目录和新资源组装的独立副本，以同样的四格次序、窗口大小和捕获方法重新操作。工作台、Music、文件库运行页面均来自该副本。工具集和文件库根面板已透出与 Music 一致的中性灰底。工具集「设置」「选择文件」和文件库「打开文件夹」均使用与 Music「添加文件」相同的半透明底色和描边，圆角仍分别为 5 与 6 CSS px。「框选屏幕」保留蓝色主操作强调。[本地修复副本同屏图](../images/integration/staged-material-four.png) · [控件与运行路径](../../tmp/qa-four-installed/run-urAQUp/facts.json)

这次预验覆盖修复资源的实际显示。合并后的安装包仍需关联分发版本及真实安装、升级结果。
