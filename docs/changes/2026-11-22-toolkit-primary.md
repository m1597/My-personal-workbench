# 工具集首页与截图验收

工作台「组件 → 工具集 → 框选屏幕」拖选红绿样张，在选区内打开铅笔画折线。直接复制后从另一窗口粘贴，与标注画布逐像素比较一致。再次绘制同样路径，从真实 Windows 另存为对话框保存 PNG，读回像素与粘贴图完全一致。测试提供隔离目录及默认文件名，实际确认使用系统对话框。Esc 关闭遮罩后可立即再次框选。前台 Windows 显示画面中截取的选区保留了红绿两色。该机本轮没有稳定复现用户描述的整屏蓝色。遮罩等原图解码和绘制后才显示；拖动中断会清理临时选区，保存时暂时解除浮层置顶。[铅笔粘贴图](../images/toolkit-primary/pencil.png) · [实际屏幕选区](../images/toolkit-primary/visible-region.png)

独立及停靠首页均只显示截图、划词、屏幕取色。独立取色直接点击像素复制十六进制值，浮层退出。停靠齿轮设置中实际录制 Ctrl+Alt+F9，通过系统按键调出取色，恢复默认 Ctrl+Alt+C 后临时键注销。API 配置迁移、双向编辑和凭据保护的隔离测试通过，未调用真实供应商。文件库改名及改尺寸联测通过。业务子页和设置页使用同一个左上返回箭头（30 × 28，悬停提示「返回」）。

可用 `python scripts/toolkit-color-desktop.py` 复测剪贴板、标注、保存、取消、取色、录制及恢复；设置环境变量 `FITBAY_VISIBLE_CAPTURE=1` 可检查实际前台浮层。测试使用隔离配置与彩色样张，短时占用屏幕及剪贴板。
