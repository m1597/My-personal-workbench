# 歌手主页曲目目录

主页分别展示曲库已收录的录音、最多五首代表作和全部歌曲。全部歌曲按 MusicBrainz 录音 MBID 分页，每页 30 条，同一首作品的不同录音分别保留。曲库本地录音始终可以直接播放。访问过的目录页会缓存在当前 Music profile，断网时仍可查看。

歌手定位会检查目录提供的艺名及别名。录音查询同时指定歌名和艺人，避免热门同名歌曲掩盖目标歌手。请求沿用每秒至多一次的队列，遇到 429 或 503 时遵守短时 Retry-After 并重试一次。长时限流和网络错误在界面提供状态及重试入口。[MusicBrainz API 的分页、请求标识和限速规则](https://musicbrainz.org/doc/MusicBrainz_API)

2026-11-14 的实网检查中，周杰伦对应周杰倫，目录返回 918 条录音。宇多田光对应宇多田ヒカル，目录返回 786 条录音。两位歌手各取连续两页，页间录音 ID 没有重复。录音数随目录更新变化。[周杰倫目录](https://musicbrainz.org/artist/a223958d-5c56-4b2c-a30a-87e357bc121b) · [宇多田ヒカル目录](https://musicbrainz.org/artist/b539e453-c4fe-47e3-8a07-8517eac74429)

独立 profile 中，从关注列表进入周杰倫主页并翻页，随后重启并断开目录请求，确认缓存页仍有 30 条，点击本地录音后播放时钟前进。测试使用复制的短音频。可用 `node scripts/check-artist-catalog-live.mjs` 重跑，截图及两页返回标题位于该次输出的验收目录。
