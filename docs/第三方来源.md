## 字体与视觉

- HarmonyOS Sans SC：仅 CSS 引用本机字体，不复制进仓库、不随软件分发。采用华为字体许可，不等同 MIT；本机具体字体包许可随安装来源保留。若要打包，先核查实际文件附带协议。[官方下载入口](https://developer.huawei.com/consumer/cn/design/resource/?catalogVersion=V1)、[公开字体许可](https://github.com/openharmony/utils_system_resources/blob/master/LICENSE_Fonts)。本轮不对字体再分发作授权结论。
- Microsoft YaHei UI / Microsoft YaHei / Segoe UI Variable：只作本机字体回退，不提取进安装包。[微软字体分发说明](https://learn.microsoft.com/en-us/typography/fonts/font-faq)。
- Fluent UI React v9 已用于按钮、窗口菜单、搜索输入框与帮助对话框；分发时保留其 MIT 版权声明。Acrylic 是独立的 Electron/Windows 系统能力。[Acrylic 指南](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)。
- Penpot 是已替代的历史视觉参考，未复制应用源码或资产。

首次安装包分发前，从实际锁定依赖及 Electron dist 的 LICENSE/LICENSES.chromium.html 等汇总完整版权与 notices，包含传递和内置组件。首次安装包已在后续打包阶段实现；没有字体拷贝或自动发布。

## 安装包来源与 notices

- electron-builder 26.18.0（MIT），仅开发打包依赖；NSIS 为其下载的安装器工具链。electron-vite 不替换，未安装 Forge。
- FitBay 窗口图标 src/renderer/public/fitbay.png 和 Windows 多尺寸图标 resources/app.ico 均由项目选定的透明斜体玻璃 F 原图转换。
- scripts/prepare-package.mjs 从锁定生产依赖提取许可证，生成包内 THIRD_PARTY_NOTICES.txt；Electron 自带 LICENSE.electron.txt 与 LICENSES.chromium.html 保留在安装目录。
- 少量 npm 包未随包带许可原文，补存上游副本：Fluent System Icons 对应 react-icons 2.0.345 的 gitHead [73ec879](https://github.com/microsoft/fluentui-system-icons/blob/73ec879377b1f412f33aca4a128aa967e6c238f0/LICENSE)，Embla 三个 8.6.0 包对应 [v8.6.0 LICENSE](https://github.com/davidjerleke/embla-carousel/blob/v8.6.0/LICENSE)。副本位于 resources/licenses，升级时复核。其余缺许可会阻止打包，不静默漏掉声明。
- 不随包分发本机 HarmonyOS/微软字体；安装机器使用其已有字体回退。

示例组件同样复用已列出的 React、Fluent UI React 与 lucide-react，独立 bundle 随示例分发；不是新增框架或第三方许可证。正式组件分发时仍需一并提供对应许可证与依赖 notices。

## Windows 窗口命中检测

桌面源码宿主使用 [Koffi](https://github.com/Koromix/koffi) 3.3.7（MIT）调用 Windows 已有的 user32 和 dwmapi。用途限于判断指针处工作台是否被其他窗口遮挡；接口只在宿主主进程内使用。当前开发部署按锁文件安装，独立安装包接入此宿主时需一起分发对应架构的二进制与许可证。
