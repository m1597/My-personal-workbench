# 项目规范与派工

- **项目规范**与用户确定范围和优先级。每项需求指定一个牵头组，列出适用入口、协作组和可实测的完成条件。补充要求合进各组原有目标，保留未完成事项。
- 用户确认派发后，消息写明绝对工作目录和分支。本机四组位于 `D:/Desktop/Projects/FitBay-teams/<组>`，分支为 `team/<组>`。平台、音乐、工具集、提示词库依次对应 `platform`、`music`、`toolkit`、`prompts`。
- 桌面 CMD 对应的目录用于集成。各组提交改动后，由集成负责人合入选定提交、统一构建并交给验收组；验收绑定该候选。集成目录已有未提交成果先核对归属。
- 集成负责人在集成目录构建并更新桌面入口的 `out`，再运行 `scripts/open-workbench.cmd --check`。沿用 `local/desktop-profile` 和原有设置、布局的存储键与来源；关闭旧窗口后双击查看新版，保留用户配置。
- 集成验收使用原对话（尾号 7244）。派工时分别记录已派发、已进入桌面构建和已实测的范围。
