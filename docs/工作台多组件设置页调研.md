# 工作台多组件设置页调研

建议从工作台右上角齿轮打开完整设置页，首屏落在「外观」。左侧列出「外观」「布局」「组件」，右侧只显示所选分类。用户找「字号」能直接调节，找「音乐设置」能进入 Music 自己的页面。以下为设计建议。

## 三个可借鉴的交互

| 来源                   | 上游怎样做                                                                                                                                                                                                 | FitBay 可采用的部分                                                                                                                            |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| PowerToys              | Always On Top 页首的模块开关控制下方快捷键等分组是否可操作。[模块页源代码](https://raw.githubusercontent.com/microsoft/PowerToys/main/src/settings-ui/Settings.UI/SettingsXAML/Views/AlwaysOnTopPage.xaml) | 组件页先展示当前状态，再显示可执行的动作。Music 的「打开」「恢复界面」「关闭」延用实际动作名称；只有产品定义了持续生效的启用策略时才使用开关。 |
| VS Code                | 设置按类分组，支持关键词搜索、「已修改」筛选、单项恢复默认值，扩展也有独立分组。[设置编辑器](https://code.visualstudio.com/docs/configure/settings)                                                        | 搜索结果显示所属范围，如「工作台 › 外观 › 字号」「组件 › Music › 音乐设置」。将「恢复材质默认值」写明，避免误以为同时重置字体或布局。          |
| Windows NavigationView | 支持左侧分类导航并随窗口宽度收起，内容区域始终显示当前分类。[NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview)                                            | 宽窗口显示分类文字，窄窗口以可展开的分类菜单代替。键盘选中分类后可进入右侧控件；关闭设置后焦点回到齿轮。                                       |

## 首版页面内容

- **外观**。保留界面语言、字体、字号和三项材质调节。固定深色玻璃从设置页首次显示即生效，直接复用现有偏好存储和预览。材质分组的恢复按钮只重置透明度、磨砂强度、背景亮度。[设计规范](设计规范.md)
- **布局**。分别标明「上次工作区」与「默认布局」，前者用于正常重启恢复，后者用于回退。列出已有命名布局，复用「窗口 → 布局」的保存、更新、切换和设为默认操作。切到空布局后，后台播放继续。[需求与规划](需求与规划.md)
- **组件**。按本机实际安装情况列出组件。已安装的 Music 提供「打开音乐设置」，由 Music 管理曲库、音源、推荐和插件。组件以独立窗口运行时也使用自己的设置入口。对工作台语言、字体、字号标明「作用于工作台」，组件独立窗口沿用其现有偏好范围。[组件运行方式](../README.md) · [工作台设置范围](设计规范.md)

验收可从一次真实操作串起：播放音乐，打开工作台设置，搜索「字号」并调整，再切换至空布局，确认仍在播放；返回设置，从「组件」进入音乐设置。另用未安装 Music 的环境核对组件列表及可用动作。两种窗口宽度都检查展开的导航与下拉菜单。
