# 推荐录音的保存许可诊断

2026-11-12 只读核查已导入的「长青SVIP音源」。当前选择网易平台，脚本声明了 `musicUrl`，没有声明平台级永久保存许可。使用该平台实际查询王菲《红豆》，目录返回 HTTP 200 和 20 个候选。3 个歌名、艺人精确匹配的候选均没有显式永久保存许可、禁止或试听标记。这次查询对应「未声明永久保存许可」，没有请求音频地址或调用模型。上游内容会变动。

旧路径把禁止、试听和未声明合并为同一条提示。现在逐条读取适用的来源和录音声明，只统计歌名和艺人都匹配的候选；多种受限状态并存时并列展示。只有明确获准的完整录音参与自动保存。存在多个可用版本时展开选择；没有匹配、连接失败及保存失败可重试，更换音乐源可直接打开设置的音乐源分类。历史记录的笼统提示会提示重新核对。

静音隔离回归见 `scripts/check-music-rights.mjs` 和 `scripts/check-music-models.mjs`。受控响应分别覆盖明确允许、明确禁止、试听、未声明、无匹配、目录 HTTP 503 和多个可选版本、同名不同艺人及三种分页对象；真实源证据只覆盖上述本次查询。
