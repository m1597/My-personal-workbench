## 历史与候选

Penpot 风格已由 Fluent 替代；只做浅色的中间状态已由黑白切换替代。Tauri、网页加 Python 服务未采用。React Flow、SQLite、独立任务进程仍属未来能力候选，本轮不添加依赖。具体选型以对应需求落地时的决定为准。

重新评估条件：实际资源占用不符合目标、首条流程大量依赖 Python、确定需要多设备或多人协作时，再针对证据比较替代方案，不凭预想重写。

## 依据

- [Electron 进程模型](https://www.electronjs.org/docs/latest/tutorial/process-model)、[安装变化](https://www.electronjs.org/docs/latest/breaking-changes)：当前包无自动 postinstall，项目显式调用 install-electron。

- [setup-node](https://github.com/actions/setup-node)、[Playwright tracing](https://playwright.dev/docs/api/class-tracing)：以实际配置和运行验收，不把上游示例当项目结果。
