# 搜索版本、关注歌手与发行曲目

搜索结果按正规化的歌名和完整艺人署名归组，识别现场、伴奏等常见版本后缀。身份不明、括号表示不同歌名、没有任何可区分的版本信息时分别展示。每一行保留原平台录音键，播放、加入歌单和主动下载均使用该行；时长来自目录秒数或分秒字段。录音地址和权限沿用已有音源。

一级页「动态」用 MusicBrainz 艺人 ID 保存关注关系。只查询关注艺人近 90 天已有正式发行、且首次发布日期落入范围的发行组；同一作品按发行组 ID 去重，按首次发布日期倒序展示单曲、专辑、EP 与原声带。查看曲目后可选择正式发行版本，点「选择版本播放」进入搜索并试听所选录音。动态与本地专辑共享发行曲目缓存，相同请求合并，成功响应缓存一小时，可手动刷新动态。动态不调用模型或占用 AI 推荐的名额。专辑详情由用户主动请求版本列表，按日期、国家、介质、曲数、版本说明和条码辨认，选择具体发行 ID 后再读取分碟曲目。按本地可用曲目的歌名、艺人及已知碟号和轨号核对；标签不全时只匹配唯一可能的曲目，跨碟同名且无法定位的录音不标为已收录，缺曲点一下进入音乐搜索。

## 实现依据

- MusicBrainz 提供艺人、发行组和发行 ID，发行组检索支持艺人 ID、首次发布日期和正式发行状态。固定访问官方端点，每次请求间隔至少 1.05 秒并携带项目联系方式。[API](https://musicbrainz.org/doc/MusicBrainz_API) · [发行组检索](https://musicbrainz.org/doc/MusicBrainz_API/Search/ReleaseGroupSearch) · [限流](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting)
- Picard 在选定具体发行后读取 recordings、artist-credits 和 media。这里借鉴按发行 ID 读取的流程，以免把普通版、豪华版曲目合并。实现独立编写，未引入 Picard 源码或依赖。[Picard 上游实现](https://github.com/metabrainz/picard/blob/master/picard/album.py)
- MusicBrainz 将核心元数据以 CC0 提供；此功能读取艺人、录音、发行、署名、日期、地区和介质等目录字段，不读取评分、标签、图片或评论。目录信息不授予音频下载许可。[数据许可](https://musicbrainz.org/doc/About/Data_License)

## 本机验证

运行 `node scripts/check-music-release-catalog.mjs`。该专项使用离屏静音 Electron、独立 profile 和替身网络响应，实际操作搜索、逐条播放并验证底栏时钟、下载指定版本、关注重启与取消、打开普通和豪华版下拉及搜索缺曲。另用独立 Electron 主进程调用真实 MusicBrainz，查询到 Radiohead 的《OK Computer》39 个候选发行；选中的 1997 年欧洲 CD 发行有 12 首，首曲为 Airbag。

另在离屏 Electron 动态页通过真实 MusicBrainz 关注 Defects，查得 2026-10-16 发行的专辑《Artificial Icons》，展开得到 11 首曲目，包括 Heresy、Signs 和 Afterglow。
