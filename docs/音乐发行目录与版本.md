# 搜索版本、关注歌手与发行曲目

搜索结果按正规化的歌名和完整艺人署名归组，识别现场、伴奏等常见版本后缀。身份不明、括号表示不同歌名、没有任何可区分的版本信息时分别展示。每一行保留原平台录音键，播放、加入歌单和主动下载均使用该行；时长来自目录秒数或分秒字段。录音地址和权限沿用已有音源。

一级页「歌手」用 MusicBrainz 艺人 ID 保存关注关系。顶部时间线显示近 90 天内的正式新发行，下方始终保留关注名单。点关注头像、歌手名或相似歌手名会打开与歌单共用的歌手主页。主页先显示可播放的已收录歌曲与正式录音，再列本地专辑和历年发行。点发行可看曲目，逐级返回恢复原列表位置。歌手主页、关注与相似歌手共用按艺人 ID 缓存的头像。优先使用本地艺人照片，其次根据 MusicBrainz 的图片或 Wikidata 关系读取 Wikimedia Commons 照片，无图时显示蓝灰色麦克风。方形发行封面匹配本地专辑。同一作品按发行组 ID 去重，按首次发布日期倒序展示单曲、专辑、EP 与原声带。查看曲目后可选择正式发行版本，点曲目旁的「播放」直接使用底部播放器试听，保留当前展开的发行和版本。未匹配到可播录音时在原地提示。动态与本地专辑共享发行曲目缓存，相同请求合并，成功响应缓存一小时，可手动刷新动态。动态不调用模型或占用 AI 推荐的名额。专辑详情由用户主动请求版本列表，按日期、国家、介质、曲数、版本说明和条码辨认，选择具体发行 ID 后再读取分碟曲目。按本地可用曲目的歌名、艺人及已知碟号和轨号核对；标签不全时只匹配唯一可能的曲目，跨碟同名且无法定位的录音不标为已收录，点击「搜索缺曲」可在同一行查看匹配录音、播放或加入自建歌单。匹配仅使用可播放的同名同艺人录音，同专辑优先。唯一对应本地文件的已收录曲目支持右键查看文件所在位置。

在「我关注的歌手」标题下输入歌手名，按回车或点击「查找歌手」，再在匹配行点「关注」。头像和名字打开主页；卡片的「已关注」按钮悬停时显示「取消关注」，点击立即取消。只关注一位歌手时自动展示相似歌手；关注多位时点头像选择。从 MusicBrainz 获取艺人获得正票的前五项风格，先按标签交集查找艺人，候选少于八位时放宽检索。逐一核对候选实际标签，按共同标签项数、双方对这些标签的支持度排序，显示至多八位及共同标签。乐队、创办或合作关系不参与排序，缺少可核实的风格时显示资料不足。相似歌手行保留已关注对象，可就地关注、取消或展开代表作试听。代表作从该艺人的正式录音中优先完整演唱版本，再按单曲和发行收录数排序。[MusicBrainz 查询与关系](https://musicbrainz.org/doc/MusicBrainz_API) · [录音与艺人检索字段](https://musicbrainz.org/doc/MusicBrainz_API/Search)

## 实现依据

- MusicBrainz 提供艺人、发行组和发行 ID，发行组检索支持艺人 ID、首次发布日期和正式发行状态。固定访问官方端点，每次请求间隔至少 1.05 秒并携带项目联系方式。[API](https://musicbrainz.org/doc/MusicBrainz_API) · [发行组检索](https://musicbrainz.org/doc/MusicBrainz_API/Search/ReleaseGroupSearch) · [限流](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting)
- Picard 在选定具体发行后读取 recordings、artist-credits 和 media。这里借鉴按发行 ID 读取的流程，以免把普通版、豪华版曲目合并。实现独立编写，未引入 Picard 源码或依赖。[Picard 上游实现](https://github.com/metabrainz/picard/blob/master/picard/album.py)
- MusicBrainz 将核心元数据以 CC0 提供；此功能读取艺人、录音、发行、署名、日期、地区和介质等目录字段，相似歌手还使用艺人风格标签查询，不读取评分、图片或评论。目录信息不授予音频下载许可。[数据许可](https://musicbrainz.org/doc/About/Data_License)

## 本机验证

运行 `node scripts/check-music-release-catalog.mjs`。该专项使用离屏静音 Electron、独立 profile 和替身网络响应，实际操作搜索、逐条播放并验证底栏时钟、下载指定版本、关注重启与取消、打开普通和豪华版下拉及搜索缺曲。另用独立 Electron 主进程调用真实 MusicBrainz，查询到 Radiohead 的《OK Computer》39 个候选发行；选中的 1997 年欧洲 CD 发行有 12 首，首曲为 Airbag。

另在离屏 Electron 动态页通过真实 MusicBrainz 关注 Defects，查得 2026-10-16 发行的专辑《Artificial Icons》，展开得到 11 首曲目，包括 Heresy、Signs 和 Afterglow。

2026-11-14 在私有桌面的独立 profile 验证了非首选版本播放后保留展开、滚动和底部播放，缺曲原位播放、加入歌单且下载文件数保持不变，唯一已收录行右键定位正确。相似歌手自动与手动选择、过滤、关注和代表作试听通过。[缺曲结果](../tmp/music-release-catalog-jO1r2a/inline-missing.png) · [相似歌手](../tmp/music-release-catalog-jO1r2a/similar-artists.png) · [照片与麦克风回退](../tmp/feed-lyrics-ui-4iseW7/动态关注.png)

使用真实 MusicBrainz 接口核验澤野弘之的关联组合，包括 NAQT VANE，后者能查到《VANE》和《TOUCH》等录音。目录信息稀少的组合允许代表作列表为空。

## 播放页作品与人员

从底部封面进入播放页，点「其他演绎」或「参与人员」。有 MusicBrainz 录音或作品标签时优先使用其 ID。没有 ID 时，只有标题、歌手、专辑和时长能唯一对应目录录音，才使用它的录音级署名。标题明确写有「翻自某歌手」时，可从原唱的同名录音追溯作品；候选指向同一作品才列其他演绎，原唱的乐手不会列作翻唱的乐手。串烧可先选择作品。曲名重复而没有可靠联系时显示「资料不足」。选择某一演绎的「查找音源」，有匹配后可在当前弹层试听或加入歌单。[作品与录音关系](https://musicbrainz.org/doc/How_to_Use_Works)

按角色显示本地文件署名、当前录音的演奏/编曲等关系以及所选作品的作曲/作词等关系。点人名通过目录艺人 ID 查其参与的其他作品；本地没有艺人 ID 时只展示曲库里的同名署名，并标明来源。MP3 使用 ID3 人员帧，FLAC 支持 Vorbis 的 COMPOSER、ARRANGER 和 PERFORMER 等字段。[Picard 标签映射](https://picard-docs.musicbrainz.org/en/latest/appendices/tag_mapping.html)

实网验证以《I BEG YOU（翻自 Aimer）》解析到《I beg you》的作品 ID，得到 Aimer 原版与上海现场、yurisa 与 Precious Jazz Orchestra 的翻唱。原版录音列 Aimer 为主唱，梶浦由記为编曲、键盘和制作；作品级署名列其作曲与作词，点本人能查到参与的《花の唄》。[作品](https://musicbrainz.org/work/04574440-b752-49eb-8ce7-75aa82113cd6) · [原版录音](https://musicbrainz.org/recording/8efb27e4-aa62-4999-821d-6482df5e7238)

后台专项通过独立 profile 和静音 Electron 验证同名异作排除、原地试听和入单、资料不足、主唱与作曲分开、多位贝斯手、编曲和其他作品。仅返回 Studio Recording 时，现场和器乐关系均不开放试听；标明 Tokyo Live、Instrumental Edition 的匹配分别通过。[其他演绎](../tmp/music-release-catalog-71eX3k/song-versions.png) · [参与人员](../tmp/music-release-catalog-71eX3k/song-credits.png)

## 从歌曲列表进入歌手和专辑

曲库、歌单、收藏、最近播放、在线搜索、推荐、队列和播放详情均可点歌手名或专辑名。没有专辑名时保留破折号。在歌手主页，可以播放已收录的歌曲，也可以点进本地专辑或目录里的正式发行。没有唯一发行版本时，从歌曲行进入的专辑页需先选版本。目录曲目优先匹配可用本地文件，再在后台按标题、艺人和专辑查找音源。播放保留当前页面。逐级点「返回」会恢复原歌单和滚动位置。

用《冬のはなし》的录音署名在 MusicBrainz 实网确认了 Given 对应的日文艺人「ギヴン」。在独立静音 profile 的受控目录与音源上验证了歌手页本地播放、进入《海へ》并在线播放、返回 38 行歌单原位置，以及春間無Nashi《神様のいうとおり》和小幻《三原色》的重名过滤、选版和窄屏入口。[艺人目录](https://musicbrainz.org/artist/5f077093-f2cd-4839-9158-51db217fba81) · [歌手主页](../tmp/music-release-catalog-KLkeHm/given-home.png) · [专辑播放](../tmp/music-release-catalog-KLkeHm/given-album.png) · [窄屏选版](../tmp/music-release-catalog-KLkeHm/三原色-album.png)

艺人头像使用 MusicBrainz 指定的艺人关系、Wikidata P18 和 Commons 缩略图，按艺人 ID 合并请求与缓存。参考 [MusicBrainz 艺人关系](https://musicbrainz.org/relationships/artist-url)、[Wikidata 实体数据](https://www.mediawiki.org/wiki/Wikibase/EntityData) 与 [Commons 缩略图接口](https://www.mediawiki.org/wiki/API:Imageinfo)。

歌手主页在组件内容宽度达到 640 像素时并排显示歌曲与专辑发行；窄窗按单列换行。使用返回按钮恢复来源搜索和位置，重复点击已选中的「曲库」直接回到全部歌曲，当前播放继续。
