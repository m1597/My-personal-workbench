# 歌曲署名与操作

曲库、歌单、播放栏和歌词页显示同一套署名。带多个结构化歌手标签的录音归到各自主页。MusicBrainz 标识优先于同名匹配。QQ 音乐、酷狗和网易云搜索结果保留来源提供的歌手数组。没有结构化标签的旧条目只按明确的顿号、分号或 feat. 标记识别多位歌手，普通组合名称中的 & 和斜杠保持完整。「未知艺人」在各个入口均显示为文本。

在线曲目可双击原地播放，或在右键菜单播放、加入歌单和下载；本地曲目可单击播放，并查看所在位置。曲目列表右侧提供加入歌单及下载或查看文件位置。发行资料中的专辑首屏显示封面与可点击的署名。歌手页可进入所属专辑，逐级返回恢复列表位置。

私有桌面静音专项 scripts/check-artist-credits.mjs 使用真实临时音频和可控目录响应，验收一首合作录音的两个歌手入口、组合名完整、未署名录音在曲库/歌单/播放页的文本与正常播放。截图在 tmp/artist-credits-IdHZaZ。
