# 歌曲署名与操作

曲库、歌单、播放栏和歌词页显示同一套署名。带多个结构化歌手标签的录音归到各自主页。MusicBrainz 标识优先于同名匹配。QQ 音乐、酷狗和网易云搜索结果保留来源提供的歌手数组。没有结构化标签的旧条目只按明确的顿号、分号或 feat. 标记识别多位歌手，普通组合名称中的 & 和斜杠保持完整。「未知艺人」在各个入口均显示为文本。

单击歌名或行内空白会选中歌曲，双击会原地播放。单击行内歌手或专辑署名进入主页，双击署名播放这一行。Windows 按当前用户的双击速度区分两种操作。播放按钮单击即生效，行末按钮各自执行对应操作。在线曲目右键可播放、加入歌单或下载，本地曲目可查看文件所在位置。曲目列表右侧提供加入歌单及下载或查看文件位置。发行资料中的专辑先使用本地封面；没有本地封面时，用已知发行组 ID 请求 Cover Art Archive 封面，网络不可用或发行无图时显示默认封面。专辑首屏的每位歌手署名都可点击。歌手页可进入所属专辑，逐级返回恢复列表位置。[Cover Art Archive API](https://musicbrainz.org/doc/Cover_Art_Archive/API)

私有桌面静音专项 scripts/check-artist-credits.mjs 使用真实临时音频和可控目录响应，验收一首合作录音的两个歌手入口、组合名完整、未署名录音在曲库/歌单/播放页的文本与正常播放。另以旧版曲库索引和真实 ID3 多艺人标签验证自动补认合作署名。截图在 tmp/artist-credits-lpJqCH。
