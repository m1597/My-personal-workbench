# FitBay 0.2.1 · Windows x64

**[下载 FitBay 工作台](https://github.com/m1597/My-personal-workbench/releases/download/v0.2.1/FitBay-Workbench-Setup-0.2.1-x64.exe)**

主安装器只安装工作台。打开「工作台设置 → 组件管理」，可以按需安装 Music、提示词仓库（文件库）和工具集。工作台从本项目的 GitHub 正式发行版下载对应安装器，校验后启动安装。首次安装的组件分别放在工作台的 `Music`、`Prompts`、`Toolkit` 子目录，已独立安装的组件沿用已登记目录升级。

已经使用 0.2.0 的用户可以在工作台检查更新，先升级工作台，再从新版设置安装所需组件。

需要离线安装时，[下载可选的完整离线包](https://github.com/m1597/My-personal-workbench/releases/download/v0.2.1/FitBay-Offline-Setup-0.2.1-x64.exe)。工作台必选，三个组件均可单独勾选。四个独立安装器和「歌曲过渡」离线插件也随本版提供。所有安装器均为未签名的 Windows x64 安装包，手动下载可用随附的 `SHA256SUMS.txt` 核验。
