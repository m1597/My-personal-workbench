# FitBay 0.2.5 · Windows x64 候选版

工作台安装后，可在设置的「组件管理」中下载安装 Music、提示词库和工具集。首次补装默认使用工作台下的 `Music`、`Prompts` 和 `Toolkit`。卸载后，独立安装器会找回仍存在的原组件目录；如果里面有与程序文件同名的文件，安装会停止，保护原文件。

需要一次装齐时，打开整合离线安装包，选择工作台目录，勾选需要的 Music、提示词库、工具集。仅工作台安装包适合希望以后从设置中补装组件的用户。

在「设置 → 更新」中选择「检查全部更新」，再点「更新全部」并确认一次。工作台最后升级。某个组件失败时，可在该行单独重试。

验收基线为正式版 0.2.4。完整离线包为 `FitBay-Offline-Setup-0.2.5-x64.exe`，工作台和三个组件亦各有独立安装包。对应文件摘要见随包的 `SHA256SUMS.txt`。
