# FitBay 0.2.0 · Windows x64

文件库现在可以独立运行，也可以停靠在工作台中。工具集增加截图标注、取色、图片拼接与压缩、文本对比和批量文件处理。Music 改进了本地曲库多选、歌单下载和播放队列定位。工作台设置可搜索组件设置、管理共享 API 连接并检查已安装产品的更新。

## 从 0.1.0 升级

在已安装的 FitBay 托盘菜单中点击「检查更新」，选择「下载并更新」，按向导完成安装。工作台和 Music 分别升级。两者都已安装时，完成第一项后重新打开 FitBay，再次检查更新，直至两个产品都显示 0.2.0。新版工作台也可通过「工作台设置 → 更新」检查已安装产品。

## 下载选择

- `FitBay-Setup-0.2.0-x64.exe` 是离线安装入口，包含工作台和可勾选的 Music。
- `FitBay-Workbench-Setup-0.2.0-x64.exe` 和 `FitBay-Music-Setup-0.2.0-x64.exe` 用于分别安装或升级对应产品。
- `FitBay-Prompts-Setup-0.2.0-x64.exe` 是文件库，`FitBay-Toolkit-Setup-0.2.0-x64.exe` 是工具集。首次安装请分别运行对应安装器。以后可通过新版工作台检查更新。
- `path.fitbayplugin` 是可选的「歌曲过渡」离线插件，可在 Music 插件设置中导入。

本版安装器未签名。更新入口在启动安装器前会校验 GitHub Release 提供的文件大小和 SHA-256。手动下载可对照随附的 `SHA256SUMS.txt`。
