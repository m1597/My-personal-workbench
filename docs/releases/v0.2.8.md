# FitBay 0.2.8 · Windows x64 本地候选

| 文件 | 用途 |
| --- | --- |
| `FitBay-Workbench-Setup-0.2.8-x64.exe` | 安装工作台，之后可在设置中按需管理组件。 |
| `FitBay-Offline-Setup-0.2.8-x64.exe` | 离线安装工作台，在同一页勾选 Music、提示词文件库和工具集。 |
| `FitBay-Music-Setup-0.2.8-x64.exe` | 单独安装或升级 Music。 |
| `FitBay-Prompts-Setup-0.2.8-x64.exe` | 单独安装或升级提示词文件库。 |
| `FitBay-Toolkit-Setup-0.2.8-x64.exe` | 单独安装或升级工具集。 |
| `path.fitbayplugin` | 本地路径插件。 |
| `SHA256SUMS.txt` | 五个安装程序和插件的 SHA-256 摘要。 |

首次安装只选择一次 FitBay 根目录，新增组件分别使用其下的 `Music`、`Prompts`、`Toolkit`。已有组件通过产品登记和文件身份校验后沿用原位置。桌面入口为 FitBay 工作台。安装程序均未签名。

工作台设置中的在线下载使用正式发行通道。本地预览的组件可以从同目录的独立安装包补装，也可以在离线安装包中一次选择。
