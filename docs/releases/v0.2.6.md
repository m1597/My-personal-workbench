# FitBay 0.2.6 · Windows x64 候选版

仅安装工作台可下载 `FitBay-Workbench-Setup-0.2.6-x64.exe`。整合离线包 `FitBay-Offline-Setup-0.2.6-x64.exe` 内含工作台与可选的 Music、提示词库和工具集。已有安装沿用原目录。所有安装包和插件的 SHA-256 均列在随包清单中。

Music 的「找歌」侧栏可切换普通搜索与 AI 推荐，歌曲和公开歌单分别保留查询、平台和结果。AI 推荐中的「本次参考」可以组合本地文件夹、自建歌单和收藏，按录音去重。清空后生成推荐不会附带曲库摘要。Music 插件目录改用 FitBay 主仓库的发行资产。

从项目 CMD 打开「工作台设置 → 更新」可查看产品开发构建版本和最新正式版。安装版在同一位置显示已安装版本。
