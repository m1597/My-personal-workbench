# FitBay 0.2.2 · Windows x64

**[下载 FitBay 工作台](https://github.com/m1597/My-personal-workbench/releases/download/v0.2.2/FitBay-Workbench-Setup-0.2.2-x64.exe)**

桌面只创建「FitBay 工作台」快捷方式。从「工作台设置 → 组件管理」安装 Music、文件库或工具集时，仍可从开始菜单独立启动各组件。组件从 0.2.1 升级时会清理桌面上指向该组件旧程序的快捷方式，同名但指向其他程序的快捷方式会保留。

工具集和文件库停靠到工作台后会沿用工作台配色与材质设置。文件库切回独立窗口时恢复独立主题。

离线安装可使用[完整离线包](https://github.com/m1597/My-personal-workbench/releases/download/v0.2.2/FitBay-Offline-Setup-0.2.2-x64.exe)。首次安装使用工作台下的 `Music`、`Prompts`、`Toolkit` 子目录，已有安装沿用原登记位置。Windows x64 安装包可用随附的 `SHA256SUMS.txt` 校验。
