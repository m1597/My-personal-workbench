# 社区音乐功能候选 · 第二轮

以下是根据社区项目整理的选题，供 FitBay Music 讨论。若先挑一个小功能，建议从「给歌曲留一个试听标记」开始。它对有歌词的歌和纯音乐都适用，也能直接用已有播放页验证体验。

## 给歌曲留一个试听标记

Mixxx 可以在播放位置设置 Hotcue，给标记命名、上色，下次点一下就跳回去。FitBay 已有进度定位。建议在播放页加「标记此处」，把曲目、时间和短名称保存在本机。比如给一段纯音乐的 01:24 标上「鼓点进来」，重新打开歌曲后就能点这个名字试听。[Mixxx 的 Hotcue 操作](https://manual.mixxx.org/2.5/en/chapters/user_interface#hotcue-controls) · [FitBay 播放页](../components/music/NowPlaying.tsx)

## 从三首听感相近的歌里挑下一首

Blissify 会分析本地音乐，再用当前歌曲找出听感相近的候选。它的交互模式默认每次给三首，选中的歌成为下一轮起点。FitBay 已有本地曲库和插播队列，可以让用户从当前歌曲打开三个候选，点一首即插播，其余队列继续保留。这项新增能力需要先比较音频分析在 Windows 上的耗时、缓存大小和实际选歌质量。[Blissify 的交互式歌单](https://github.com/Polochon-street/blissify-rs#make-an-interactive-playlist) · [FitBay 播放队列](../README.md)

## 把听过的歌编成本周回听

ListenBrainz 的 Weekly Jams 用听过的作品生成每周歌单。FitBay 现有每日推荐面向曲库外的新歌，最近播放里已经有本机历史。可增加「本周回听」入口，每周从收藏或多次完整试听过的曲目中选出若干首，混入一两首近期少听的老歌，按周保留曲序。没有足够历史时就列出实际选到的首数。[ListenBrainz 官方歌单实例及说明](https://listenbrainz.org/user/dethmetaljeff/recommendations/) · [FitBay 最近播放](../components/music/LibraryTools.tsx) · [现有推荐范围](需求与规划.md)
