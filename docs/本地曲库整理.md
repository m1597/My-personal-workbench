# 本地曲库整理

在 Music 的「设置 → 本地曲库 → 曲库整理」中启动扫描。每组重复录音可指定一份保留文件，默认优先收藏项。「仅移除其他索引」保留磁盘文件。「将其他文件移至回收站」在系统确认框列出实际路径。扫描比较文件 SHA-256，对时长相近且在解码限额内的文件，再用沙箱内的录音指纹比较。每个参与移除的文件和保留项都在操作前再次校验。

去曲序号支持 01 -、1.、[03] 和两位数字加空格。预览按文件勾选，同名 LRC 随文件移动。更新原曲目 ID 的路径，收藏和歌单继续引用原录音。目标音频、歌词冲突及同目录其他录音可能共用歌词时均跳过。通过同卷独占硬链接保留文件身份，提交数据库后再释放旧名称。文件系统不支持硬链接时会跳过该文件。

2026-11-14 在后台私有桌面，以临时曲库、静音 Electron 从设置入口复验。字节相同、标签不同的同一录音归入一组，同名不同录音保留。实测仅移除索引、预览后文件变化、取消回收和真实回收临时副本。改名后验证歌词字节、收藏状态、歌单成员 ID，重启后可播放。原始截图留在 tmp/library-cleanup-0QNON6，复验命令为 python tmp/ui-eight-private.py scripts/check-library-cleanup.mjs。
