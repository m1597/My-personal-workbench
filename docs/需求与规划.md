# 需求与规划

## 已确认

- 单人、本地优先的个人工作台，通过模块组织创作工具与自己的工作流。
- Electron + React + TypeScript + Vite、Dockview；四个占位模块支持拖拽分屏、标签分组、尺寸调整、关闭重开、最大化和恢复。
- Fluent 黑白磨砂，默认深色、记住主题；中文优先本机 HarmonyOS Sans SC，回退微软雅黑 UI。
- 布局自动保存位置、尺寸、分组、打开状态和活动面板；空布局有效。重置会持久化；损坏、未知模块或不兼容版本回退默认。最大化为临时状态。
- 每个完成事项验证后独立 commit；push 单独授权；调试默认后台。
- 工作台和业务组件分开安装、升级、卸载；第三方可按统一规范开发组件，无需下载其他业务组件。组件支持独立启动、加入/分离工作台、必要状态连续；音乐须避免重复播放/切换中断。卸载默认保留个人素材。
- 上述是已确认产品目标；已选择公共宿主方案 B，先验证示例，音乐库继续暂停。完整安装升级与媒体会话尚未实现。
