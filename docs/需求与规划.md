# 需求与规划

## 已确认

- 单人、本地优先的个人工作台，通过模块组织创作工具与自己的工作流。
- Electron + React + TypeScript + Vite、Dockview；真实组件支持拖拽分屏、标签分组、尺寸调整、关闭重开、最大化和恢复。
- Fluent 固定深色玻璃；中文优先本机 HarmonyOS Sans SC，回退微软雅黑 UI。
- 布局自动保存位置、尺寸、分组、打开状态和活动面板；首次启动为空工作区，空布局有效。「窗口 → 布局」支持命名保存、显式更新、切换、设为默认与还原默认。重启优先恢复最后实时布局；损坏、未知模块或不兼容版本回退默认。切换到无 Music 的布局时继续原播放会话。最大化为临时状态。
- Music 本地曲库支持歌曲和专辑两种视图。专辑按本地标签和艺人区分，同专辑可共用内嵌封面；播放整张沿用底部播放器。歌曲推荐的系统歌单仅展示当前轮已入库成员，物理文件夹按实际收录文件展示。
- 专辑首次打开即列出全部，支持搜索和按收录曲数升降序。进入详情后返回，继续浏览刚才的位置。整张专辑可按碟号和轨号加入下一首。
- 歌单内可拖动调整顺序，也可按添加时间、歌名或艺人双向排序。从歌单移除成员后可撤销。右键歌单可按保存顺序导出 UTF-8 M3U8。
- 点底栏封面打开歌词页，点爱心收藏当前录音。歌词随播放平滑换行，手动滚动后可自由阅读，点「回到当前歌词」恢复跟随，点有时间的歌词从该句播放。专辑、底栏和歌词页沿用相同的本地封面及离线默认图。
- Music 的首次引导跟随真实控件；每日推荐展示本批已下载入库的新歌，目标首数默认五首，跨批、跨日排除已推荐曲目，保留已入库歌曲及显式反馈。完整视图、仅播放栏和后台共用播放会话，菜单勾选表示仍在运行。见[组件开发](组件开发.md#模型推荐)。
- 每个完成事项验证后独立 commit；push 单独授权；调试默认后台。
- 工作台和业务组件分开安装、升级、卸载；第三方可按统一规范开发组件，无需下载其他业务组件。组件支持独立启动、加入/分离工作台、必要状态连续；音乐须避免重复播放/切换中断。卸载默认保留个人素材。
- 上述是已确认产品目标；已选择公共宿主方案 B，先验证示例，第一方音乐试听已获一期授权。正式安装升级待验证，音乐媒体会话见一期任务。

## 开发优先级

工作台固定使用原有默认深色玻璃。桌面入口已支持组件标题栏吸附与直接拖标签分离，后台验收记录见 [当前变更](../openspec/changes/dock-component-window/tasks.md)。

1. **补原型关键门槛**：在用户明确允许的前台时间或独立测试桌面验证真实标题栏拖入、停靠、分离、取消、遮挡、焦点及多屏 DPI；沿用隔离 profile。当前仅后台约束下保留此项待验，不能再用消息模拟宣布完成。验证结果决定是否继续采用现有实现路线。
2. **Windows 安装交付**：工作台、Music 分别构建安装器，离线入口可勾选 Music，之后也可独立补装。Music 内部插件延期。当前实测范围见[任务记录](任务记录.md)。跨版本覆盖升级、回退与独立 Windows 机器验收另行安排。
3. **最后再规划组件生产化**：基于原型门槛证据，写变更记录细化正式宿主分发、协议兼容、数据单写入、布局迁移与权限边界，重大方案先确认。音乐会话现由第一方组件实施，验收见 [音乐试听一期](../openspec/changes/archive/2026-11-13-add-music-recommendation-audition/tasks.md)。

第一方音乐试听已获一期授权；其他资产模块、AI 节点图、通用数据库层、SDK、插件市场、自动更新亦未进入实施。具体业务功能按后续确认的范围启动。

本地曲库已纳入音乐组件；用户手选文件或目录，原地索引并播放。范围和验收见 [本地歌曲库一期](../openspec/changes/archive/2026-11-12-add-local-music-library/tasks.md)。

「设置」支持从本地文件和在线直链导入洛雪兼容源。在「在线找歌」输入关键词并按回车，可按录音版本和音质在线播放、加入歌单或下载至指定目录。协议覆盖和操作见[组件开发](组件开发.md#洛雪音乐源)。

「每日推荐」提供按歌手和按风格两种方式。可以手填条件，可授权结合本机保存的增量审美文档。推荐录音按许可和版本自动保存到「歌曲推荐」歌单，歧义和失败按曲目处理。模型设置提供 DeepSeek、OpenAI、Claude、Gemini 和离线示例。
