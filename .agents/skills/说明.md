# OpenSpec 工作流

用 openspec-explore 调查问题，openspec-propose 创建提案，openspec-update-change 修订变更，openspec-apply-change 执行任务，openspec-sync-specs 同步规范，openspec-archive-change 归档。

[提案技能](openspec-propose/SKILL.md) · [项目开发流程](../../docs/开发流程.md)

六份技能由 OpenSpec CLI 的 `agents` 适配生成，沿用[上游 MIT 许可证](OpenSpec-LICENSE.txt)。项目格式化器跳过这些技能原件。
